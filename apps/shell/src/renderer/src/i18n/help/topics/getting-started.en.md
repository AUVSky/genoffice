# Quick start: the interface and the basics

Office runs entirely on your machine. One window holds five editors — Word (`.docx`), Excel (`.xlsx`), PowerPoint (`.pptx`), PDF and Markdown. The files are real Office files, interchangeable with Word, Excel and PowerPoint. No network is used.

## The start screen

When no document is open, the window shows the start screen: a greeting, five quick-create cards (Word, Excel, PPT, Markdown, PDF), **Open Local File**, the file-type filter, the search box and your recent files.

The start screen is not a tab. Opening a document replaces it; closing the last document brings it back.

## Creating and opening

- Click a quick-create card on the start screen.
- Use **File ▸ New**: Word (⌘N/ctrl+N), Excel, PowerPoint, Markdown or PDF.
- Drag a file onto the window, or double-click a file in your file manager.

A new document opens untitled; the file is created on disk at the first save.

## Saving

**Save** (⌘S/ctrl+S) writes to the file you opened. An untitled document asks where to save. **Save As** always asks. AutoSave can write on a timer; the tab shows an unsaved marker until the write lands.

Settings live behind the **Settings** button at the top right.
