# 快速入门：界面与基本操作

Office 完全在你的电脑上运行。一个窗口里装着五个编辑器：Word（`.docx`）、Excel（`.xlsx`）、PowerPoint（`.pptx`）、PDF 和 Markdown。文件是真正的 Office 文件，与 Word、Excel、PowerPoint 互通，全程不需要联网。

## 启动页

没有打开文档时，窗口显示启动页：问候语、五张新建卡片（Word、Excel、PPT、Markdown、PDF）、**打开本地文件**、类型筛选、搜索框和最近文件。

启动页不是标签页。打开文档后它会让出位置；关闭最后一个文档，它会回来。

## 新建与打开

- 点启动页上的新建卡片。
- 菜单 **文件 ▸ 新建**：Word（⌘N/ctrl+N）、Excel、PPT、Markdown 或 PDF。
- 把文件拖进窗口，或在文件管理器里双击文件。

新文档先以「未命名」状态打开，第一次保存时才在磁盘上创建文件。

## 保存

**保存**（⌘S/ctrl+S）写回已打开的文件；未命名文档会先询问保存位置。**另存为**每次都会询问。自动保存可以按定时器写盘；写入完成前，标签上会显示未保存标记。

设置入口在右上角的 **设置** 按钮。
