# 标签页与窗口

每个打开的文档都是顶部标签条里的一个标签。启动页不是标签：它只在没有文档打开时出现。

- **切换**：点击标签，或用标签切换快捷键前后跳转。
- **新建**：**+** 按钮用于新建文档或选择文件。
- **关闭**：标签上的 **×**、鼠标中键，或 ⌘W/ctrl+W。有未保存改动时会先询问。
- **重新打开**：标签菜单里可以重新打开刚关闭的标签，关闭记录保留到本次会话结束。
- **排序**：按住标签在标签条里拖动。
- **拖出窗口**：把标签拖离标签条，会放进独立窗口；拖回标签条即可重新停靠。
- **标签菜单**：右键标签可保存、另存为、打印、在新窗口打开、左右分屏、固定、重命名、创建副本、在文件夹中显示和关闭。

关闭最后一个文档后，启动页会回来。菜单 **文件 ▸ 返回首页** 可以直接回到启动页。
